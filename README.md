# BUAA Compiler Web UI

A lightweight web UI for the `buaa-compiler-wasm` compiler module, built with React, Vite, TypeScript, Monaco Editor, and Tailwind CSS.

WASM compiler module:

[buaa-compiler-wasm](https://github.com/samlee1020/buaa-compiler-wasm)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This project is designed for static deployment platforms such as Vercel and Cloudflare.

Online demo:

- [Vercel Demo](https://samlee-buaa-compiler-webui-p27wfqimz-samlee1020s-projects.vercel.app/)
- [Cloudflare Demo](https://buaa-compiler-webui.samlee1020.workers.dev)
